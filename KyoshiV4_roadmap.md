# Kyoshi v4.0 roadmap: the owner's feedback, app by app
This file is a **log of the owner's comments**, gathered one app at a time. Later, a stronger model reads all of it and writes
one targeted action plan for implementation. Nothing in the apps changes while this file is being filled.

## Rules for the model recording comments (read before editing)
1. **Record only.** Do not change app or core code, versions or changelogs. Do not start implementing anything.
2. **Verbatim.** Put the owner's words under "Comments (verbatim)" exactly as given, one dated bullet per comment. No rewording, no summary, no merging, no deleting.
3. **Sort, don't edit.** After logging a comment verbatim you may also copy it (unchanged) under the single best-fitting subheading (Keep / Change / Add / Remove / Bugs / Open questions). If unsure, leave it only in the verbatim log.
4. **Clarify, don't decide.** Ask at most one short clarifying question per comment, and only if it is truly unclear. Record the answer verbatim under "Open questions" with the date.
5. **Never restructure this file.** Only add bullets inside the existing sections. Do not rename, reorder, add or remove headings.
6. **Stay in your section.** Edit only the app the owner is currently talking about. A comment that concerns another app or core goes in that section's log, prefixed with `(from <App>)`.
7. Commit after each app's session. Per the owner's choice, this planning file goes straight to `main`.

Comment format: `- 2026-10-03: <the owner's words>`

## Current state (copied from each app's CLAUDE.md, for orientation only)
- **Core**: shared DNA (storage, sync, backup, pop-ups, meetings, inbox/agenda, dev mode, bug reports, wake lock, PDF tools, shell).
- **Momo**: weekly time budget, YNAB-style for hours; the hub other apps feed.
- **Bosco**: weight tracker with projections and GLP-1 dosing.
- **Wan Shi Tong**: media recommendations backlog (3 in progress, 1 up next).
- **Appa**: preventive maintenance and records; jobs to Momo; PDF reports with proof.
- **Hawky**: errands and pop-up tasks; quick add on the phone.
- **Iroh**: goals ladder (vision, year, season); hours fill Momo's cards.
- **Badgermole**: workouts; routines in rotation, set logging, PRs, streak.
- **Turtleduck**: meals; recipes, two-week plan, grocery lists, cook view.
- **Pabu**: keep in touch; who's due, birthdays as events.
